# holbertonschool-higher_level_programming

Holberton School Higher Level Programming curriculum repository containing projects on Python fundamentals, OOP, data structures, web development, databases, and testing.

## Directory structure

Comprehensive list of project directories:

- `exercices/` – Functional programming with `map`, `filter`, `reduce`
- `javascript-dom_manipulation/` – DOM manipulation with event listeners
- `javascript-warm_up/` – JavaScript basics and warm-up exercises
- `loan_calculator/` – Financial calculator CLI application
- `python-abc/` – Abstract Base Classes and advanced OOP patterns
- `python-classes/` – Introduction to classes with `Square` class
- `python-data_structures/` – Lists, tuples, matrices, and nested data
- `python-everything_is_object/` – Python object model theory
- `python-exceptions/` – Exception handling and safe functions
- `python-hello_world/` – Basic printing and string operations
- `python-if_else_loops_functions/` – Control flow and basic algorithms
- `python-import_modules/` – Modules, imports, and CLI arguments
- `python-inheritance/` – Class hierarchies and polymorphism
- `python-input_output/` – File I/O, JSON serialization
- `python-more_classes/` – Advanced `Rectangle` class with properties
- `python-more_data_structures/` – Dictionaries, sets, advanced operations
- `python-object_relational_mapping/` – SQLAlchemy ORM with MySQL
- `python-serialization/` – JSON, Pickle, CSV, XML serialization
- `python-server_side_rendering/` – Flask + Jinja2 web application
- `python-test_driven_development/` – Unit testing with `unittest`
- `restful-api/` – REST APIs with Flask and HTTP methods
- `sql_exercices/` – SQL database creation and manipulation
- `SQL_introduction/` – MySQL basics and CRUD operations

## Technologies

- **Languages**: Python 3, JavaScript, SQL (MySQL)
- **Frameworks**: Flask, SQLAlchemy, Jinja2
- **Databases**: MySQL, SQLite
- **Testing**: `unittest` framework
- **Tools**: Virtual environments, pip package management

## Requirements

- Python 3.8+
- MySQL 5.7+ (for database projects)
- Node.js (for JavaScript projects)
- Git and GitHub for version control

## Setup and usage

1. Clone the repository:
```git clone (https://github.com/sokolgj19/holbertonschool-higher_level_programming/) ```
```cd holbertonschool-higher_level_programming```

2. For Python projects with virtual environments:
```python3 -m venv venv source venv/bin/activate```

3. Navigate to a specific project:
```cd python-classes ```

4. For database projects, create and configure your MySQL database first.

Each project directory contains its own `README.md` with specific instructions, learning objectives, and usage examples.

## Learning path

```
	1.	Basics → python-hello_world, python-if_else_loops_functions
	2.	OOP → python-classes, python-more_classes, python-inheritance
	3.	Data → python-data_structures, python-more_data_structures
	4.	Advanced → python-abc, python-everything_is_object
	5.	Web → javascript-warm_up, javascript-dom_manipulation, restful-api
	6.	Backend → python-server_side_rendering, python-object_relational_mapping
	7.	Databases → SQL_introduction, sql_exercices
	8.	Testing → python-test_driven_development
```
